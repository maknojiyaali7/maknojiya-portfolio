# Maknojiya Abidali — Flutter Developer Portfolio

A self-contained, responsive HTML portfolio site for showcasing Flutter development work and attracting agency subcontracting and direct client projects.

## Deploy
GitHub Actions deploys this site to GitHub Pages on every push to `main`. In the repository settings, set **Pages → Build and deployment → Source** to **GitHub Actions** if it is not selected already.
